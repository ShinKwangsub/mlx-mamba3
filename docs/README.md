# Mamba-3 프로젝트 문서

이 프로젝트의 문서는 두 갈래로 나뉜다.

## 학습 자료

[learning/README.md](learning/README.md)에서 시작한다.

AI와 Mamba-3를 처음 배우는 사람이 다음 token 예측, loss, gradient, weight, recurrent state, 외부 기억, LoRA를 순서대로 이해하도록 구성한다. 설명을 읽은 뒤 `exercises/`의 문제와 해설을 사용한다.

## 연구 자료

[research/README.md](research/README.md)에서 현재 연구 단계와 문서 역할을 확인한다.

연구 자료에는 원본 코드 분석, 실행 검증, 학습과 망각 실험, 전체 연구 로드맵, 단계별 통과 기준이 들어 있다.

## 권장 순서

```text
학습 과정에서 개념 이해
→ 연습문제에서 자신의 예측 작성
→ 연구 일지에서 실제 결과 확인
→ 연구 로드맵에서 다음 실험의 이유 확인
→ 새로운 질문과 실험 제안 작성
```
