# Mamba-3 연구 문서 안내

이 디렉터리는 Mamba-3 자체의 동작 검증과 경량 적응형 기억 시스템 연구를 기록한다.

AI와 Mamba-3 개념을 순서대로 학습하려면 [학습 과정](../learning/README.md)에서 시작한다.

## 현재 연구 단계

- 현재 단계: `0단계 기반 검증 완료`
- 다음 단계: `1단계 Mamba recurrent state 특성 검증`
- 아직 시작하지 않은 것: 외부 기억 통합, 자동 기억 선별, 실제 대화 중 LoRA 학습, Transformer 장기지식 엔진 연결

현재 tiny 실험으로 확인된 것은 Mamba-3 구현이 실행되고, 작은 말뭉치를 학습하며, checkpoint와 LoRA adapter를 저장하고 다시 불러올 수 있다는 점이다. 이것은 실제 한국어 대화 능력이나 Mamba의 실시간 학습 우위를 의미하지 않는다.

## 기준 문서

연구 목표, 용어, 단계별 가설, 통과 기준은 [research-roadmap.md](research-roadmap.md)를 단일 기준 문서로 사용한다. 새로운 구현이나 큰 실험을 시작하기 전에 반드시 현재 단계의 통과 조건을 확인한다.

## 연구 진행 규칙

1. 한 실험에서는 핵심 가설 하나만 판정한다.
2. 성공 기준과 실패 기준은 실행 전에 문서에 적는다.
3. Mamba 고유의 장점은 같은 조건의 Transformer 기준 모델과 비교하기 전에는 주장하지 않는다.
4. tiny corpus overfit 결과를 실제 언어 능력이나 일반화 성능으로 해석하지 않는다.
5. 실패, 비결정성, 반례도 성공 결과와 같은 비중으로 기록한다.
6. 다음 단계의 구현은 현재 단계의 통과 조건을 만족한 뒤 시작한다.
