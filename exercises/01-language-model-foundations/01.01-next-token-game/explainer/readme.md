# 다음 token 예측 게임

## 1. 텍스트는 바로 모델에 들어가지 않는다

모델은 문자열을 직접 계산하지 않는다. tokenizer가 텍스트를 token ID로 바꾼다.

```text
"맘바 연구"
→ tokenizer
→ [12, 31, 7, 44, 18]
```

실제 tokenizer는 단어 조각이나 byte를 사용할 수 있다. 현재 연구의 `CharTokenizer`는 실험을 단순하게 만들기 위해 글자 단위를 사용한다.

## 2. 다음 token 학습 데이터 만들기

token ID가 다음과 같다고 하자.

```text
[10, 20, 30, 40]
```

다음 token 예측의 input과 target은 한 칸 어긋난다.

```text
input:  [10, 20, 30]
target: [20, 30, 40]
```

모델은 다음 세 문제를 한 번에 학습한다.

```text
10 다음에는 20
10, 20 다음에는 30
10, 20, 30 다음에는 40
```

## 3. 모델은 하나의 답만 바로 내지 않는다

모델의 마지막 layer는 vocabulary의 모든 token에 점수인 logits를 낸다.

```text
token A: 2.4
token B: 0.7
token C: -1.1
```

softmax를 거치면 확률 분포가 된다. 가장 높은 확률의 token을 고를 수도 있고, 확률에 따라 sampling할 수도 있다.

## 4. 왜 단순한 게임으로 복잡한 패턴을 배우는가

다음 token을 잘 맞히려면 단순한 철자만 알아서는 부족하다. 긴 문장에서 다음 내용을 예측하려면 문법, 의미, 사실, 대화 흐름, 코드 구조와 추론 형식을 내부에 압축해야 한다.

하지만 다음 token loss가 낮다는 사실만으로 이해나 지능을 증명할 수는 없다. 학습 문장을 그대로 외워도 loss는 낮아질 수 있다.

## 5. 현재 tiny 실험의 의미

우리 tiny Mamba는 짧은 한국어 corpus의 다음 글자를 외웠다. 이 결과가 확인한 것은 학습 경로가 작동한다는 사실이다.

확인하지 못한 것은 다음과 같다.

- 새로운 문장에 대한 일반화
- 실제 한국어 대화 능력
- 지식과 추론 능력
- Mamba가 Transformer보다 우수한지 여부

이제 [문제](../problem/readme.md)에 자신의 말로 답한다.
