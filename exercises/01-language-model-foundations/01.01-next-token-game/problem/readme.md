# 다음 token 예측 문제

1. token ID가 `[4, 9, 2, 7, 5]`일 때 next-token input과 target을 작성하라.
2. vocabulary가 `가`, `나`, `다` 세 token이고 logits가 각각 `2.0`, `1.0`, `-1.0`이라면 어떤 token의 확률이 가장 높을까?
3. logits와 probability의 차이를 자신의 말로 설명하라.
4. 같은 문장을 여러 번 학습해 loss가 거의 0이 됐다. 이것만으로 일반화에 성공했다고 말할 수 없는 이유는 무엇인가?
5. 다음 token 예측만으로 문법이나 사실 패턴을 배울 수 있는 이유를 한 문장으로 설명하라.
6. 현재 `CharTokenizer`가 실제 한국어 foundation model용 tokenizer로 부적합한 이유를 두 가지 생각해보라.

답을 작성한 뒤 [해설](../solution/readme.md)을 확인한다.
