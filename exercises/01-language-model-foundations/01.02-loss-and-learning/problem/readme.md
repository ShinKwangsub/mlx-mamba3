# loss와 학습 문제

1. 모델 A가 정답 token에 `0.2`, 모델 B가 `0.8`의 확률을 줬다. 어느 모델의 해당 token loss가 더 낮을까?
2. gradient를 계산했지만 `optimizer.update()`를 호출하지 않았다. weight 학습이 일어났다고 할 수 있을까?
3. training loss가 `5.0`에서 `0.1`로 내려갔지만 validation loss는 `5.2`에서 `6.0`으로 올라갔다. 가장 먼저 의심할 현상은 무엇인가?
4. 새 corpus loss가 내려가고 기존 corpus loss가 크게 올라갔다. 이 결과를 무엇이라고 부를 수 있는가?
5. learning rate가 너무 큰 실험에서 같은 seed의 작은 GPU 수치 차이가 왜 나중에 크게 벌어질 수 있을까?
6. 좋은 학습 결과를 판단하기 위해 loss 외에 확인할 항목을 세 가지 작성하라.

답을 작성한 뒤 [해설](../solution/readme.md)을 확인한다.
