# weight, state, 외부 기억 문제

각 항목을 `현재 context`, `Mamba state`, `외부 기억`, `LoRA 후보`, `폐기` 중 하나 이상으로 분류하고 이유를 작성한다.

1. 사용자가 방금 질문한 문장의 앞부분
2. “오늘 실험 브랜치의 최신 commit은 590a473이다.”
3. 사용자가 모든 연구 문서를 한국어로 작성하라고 여러 번 확인한 규칙
4. 모델이 근거 없이 추측한 사용자 생일
5. 긴 token stream을 읽으며 Mamba layer 안에서 갱신된 tensor
6. 다음 주에 변경될 수 있는 프로젝트 일정
7. 여러 실험에서 반복 확인된 “결과를 말할 때 한계를 함께 기록한다”는 행동 방식
8. 사용자가 삭제해 달라고 요청한 개인정보

추가 질문:

10. LoRA를 비활성화하면 base model의 원래 출력으로 돌아갈 수 있다는 점이 왜 연구에 유리할까?
