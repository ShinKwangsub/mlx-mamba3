# weight, state, 외부 기억 해설

1. 현재 context다. 처리 중에는 Mamba state에도 영향을 준다.
2. 외부 기억이 적합하다. 정확한 출처와 현재성을 확인하고 나중에 수정할 수 있어야 한다.
3. 외부 기억에 명시적으로 보존할 수 있고, 충분히 반복되고 안정적이라면 LoRA 후보도 될 수 있다. 바로 LoRA로 보내지는 않는다.
4. 폐기해야 한다. 모델의 추측을 사실처럼 저장하거나 학습하면 오류가 강화된다.
5. Mamba recurrent state다. weight 학습 결과가 아니다.
6. 외부 기억이 적합하다. 변경 가능한 사실을 weight에 넣으면 수정과 삭제가 어렵다.
7. LoRA 후보가 될 수 있다. 여러 사례에서 확인되고 일반화 가능한 행동 패턴이기 때문이다.
8. 폐기하고 외부 저장소에서도 삭제해야 한다. LoRA 학습 후보에서는 반드시 제외한다.
9. 학습 시간, 검증 비용, 망각 위험, 삭제 난이도가 생긴다. 출처가 흐려지고 오래된 사실이 weight에 남을 수도 있다.
10. adapter를 실험 단위로 교체하고 실패 시 rollback할 수 있다. 다만 base 출력 복원이 곧 전체 시스템 상태 복원을 뜻하지는 않는다.

분류에는 항상 하나의 절대 정답만 있는 것은 아니다. 중요한 것은 정보의 변경 가능성, 반복성, 민감도, 출처 필요성, 일반화 가능성을 근거로 설명하는 것이다.
