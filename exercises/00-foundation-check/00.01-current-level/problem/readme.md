# 현재 수준 진단

각 질문에 다음 점수를 스스로 매긴다.

- `0`: 처음 보는 내용이다.
- `1`: 들어봤지만 설명하기 어렵다.
- `2`: 자신의 말과 예시로 설명할 수 있다.

검색하거나 AI에게 묻지 않고 먼저 답한다.

## Python과 데이터

1. Python의 `list`와 `dictionary`는 어떻게 다른가?
2. function의 입력값과 반환값은 무엇인가?
3. shape가 `(2, 4, 8)`인 tensor에는 숫자가 총 몇 개 있는가?
4. `ids = [10, 20, 30, 40]`일 때 `ids[:-1]`과 `ids[1:]`의 결과는 무엇인가?
5. 같은 model function을 여러 입력에 호출하는 것과 model을 학습시키는 것은 어떻게 다른가?

## 수학 직관

6. 확률 `0.1`, `0.3`, `0.6`의 합은 얼마이며 왜 중요한가?
7. 평균은 어떤 정보를 보여주고 어떤 정보를 숨길 수 있는가?
8. 정답 확률이 `0.1`에서 `0.8`로 올라가면 cross-entropy loss는 어느 방향으로 움직일까?
9. 기울기 또는 gradient라는 말을 자신의 예시로 설명해보라.
10. learning rate가 지나치게 크면 어떤 일이 생길 수 있을까?

## AI와 Mamba

11. training과 inference의 차이는 무엇인가?
12. overfit과 generalization의 차이는 무엇인가?
13. model weight와 Mamba recurrent state는 어떻게 다른가?
14. LoRA는 base model 전체 학습과 무엇이 다른가?
15. 외부 메모리에 저장한 사실은 왜 항상 LoRA로 학습할 필요가 없는가?

## 결과 해석

- `0~10점`: Python 자료구조와 확률 직관부터 천천히 시작한다.
- `11~20점`: 언어 모델 기초 단원을 진행하면서 부족한 선수 지식을 보충한다.
- `21~26점`: 기초 단원을 빠르게 복습한 뒤 코드 읽기를 병행한다.
- `27~30점`: 설명보다 실험 설계 문제에 더 많은 시간을 사용한다.

점수가 낮아도 연구를 시작할 수 있다. 이 진단의 목적은 모르는 것을 숨기지 않고 학습 순서를 정하는 것이다.
