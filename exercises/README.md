# Mamba-3 학습 연습문제

각 연습은 가능한 경우 다음 세 부분으로 구성한다.

- `explainer`: 개념 설명
- `problem`: 자신의 말로 답하는 문제
- `solution`: 권장 해설과 비판적 해석

권장 순서:

1. [현재 수준 진단](00-foundation-check/00.01-current-level/problem/readme.md)
2. [다음 token 예측](01-language-model-foundations/01.01-next-token-game/explainer/readme.md)
3. [loss와 학습](01-language-model-foundations/01.02-loss-and-learning/explainer/readme.md)
4. [weight, state, 외부 기억](01-language-model-foundations/01.03-weights-state-memory/explainer/readme.md)
5. [tiny 학습 코드 읽기](01-language-model-foundations/01.04-read-tiny-training/explainer/readme.md)

문제를 풀 때는 해설을 먼저 열지 않는다. 정답을 맞히는 것보다 자신의 예상과 해설이 왜 달랐는지를 설명하는 것이 중요하다.
